# ds-chat 密钥聊天室

打开网页，输入一段长密钥就进入房间；对方输入同一段密钥，就进入同一个房间聊天。

## 一键安装

用 root 登录服务器，粘贴下面这一行，回车：

```bash
curl -fsSL https://raw.githubusercontent.com/imthnio/ds-chat/main/install.sh | bash
```

它会问几个问题，不懂就一路回车：

1. **是否通过 Cloudflare 访问**：域名挂了 Cloudflare（小云朵是橙色）就选 y，见下面“挂 Cloudflare”。
2. **域名**：有域名（已经解析到这台服务器）就填上，会自动申请免费证书；没有就直接回车，用 IP 访问。
3. **端口**：默认 443。NAT 小鸡填商家分配给你的端口。
4. **管理员密码**：回车就自动生成一个。

装完会显示聊天地址、管理后台地址和管理员密码。

> 没填域名时，浏览器第一次打开会提示“不安全 / 不是私密连接”，点 **高级 → 继续访问** 就行，消息照样是加密的。

支持 Debian / Ubuntu / CentOS / Alpine，Python 3.6～3.14 都能跑，64 MB 内存的小鸡也行，不需要 nginx，也不用装别的。

### 更新、改设置、卸载

还是运行上面那一行命令。已经装过的服务器会弹出菜单：

```
1) 更新到最新版（设置和聊天记录都保留）    ← 直接回车就是这个
2) 修改设置（域名 / 端口 / 管理员密码）
3) 查看地址和管理员密码
4) 重启服务
5) 卸载
0) 退出
```

### 挂 Cloudflare

安装时“通过 Cloudflare 访问”选 y，填上域名。装完后在 Cloudflare 后台设置这几处（装完屏幕上也会提示）：

1. **DNS**：添加 A 记录，域名指向服务器 IP，小云朵点成橙色。
2. **SSL/TLS 加密模式选“完全 (Full)”**。不要选“灵活”（会打不开），也不要选“完全（严格）”。
3. **端口不是 443 时**：规则 → Origin Rules → 新建规则，主机名等于你的域名时，目标端口改写为你的端口（免费版就能用）。

之后大家直接打开 `https://你的域名`，不用带端口，也不会再有“不安全”提示。服务器会从 Cloudflare 转发的请求里读出访问者的真实 IP（只认真正来自 Cloudflare 的请求）。

## 功能

- **密钥不出浏览器**：房间号和加密钥匙都在浏览器里由密钥推导出来，服务器只见到房间号和密文，管理员也看不到聊天内容。
- **可以退出再回来**：聊天记录加密保存在服务器上，过段时间用同一段密钥进来还在。
- **创建者**：第一个进入房间的人。换浏览器或清了浏览器数据会失去创建者身份。
- **人数上限**：默认最多 7 人（含创建者，创建者的位置一直保留），创建者和管理员可以调成 2～7 人。满了之后新的人进不来。
- **销毁**：创建者和管理员可以立即销毁房间，或者设 1～12 小时倒计时自动销毁。房间和全部聊天记录一起删除。
- **管理后台**：网址后面加 `/admin`，可以看全部房间、调人数上限、设倒计时、立即销毁。
- 双方看到的 6 位房间码一样，就说明在同一个房间。

## 安全说明

- 密钥越长越难猜，建议直接用页面上的“随机生成”。
- 拿到同一段密钥的人都能进房间、看到全部记录，所以密钥要私下告诉对方。
- 服务器能看到：房间号（密钥的哈希）、消息时间和长度、在线人数、访问 IP。看不到密钥和消息内容。

## 手动运行（高级）

不用安装脚本也行，只需要 Python 3.6 以上：`python3 server.py`。用环境变量设置：

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `8080` | 端口 |
| `HOST` | `0.0.0.0` | 监听地址 |
| `CERT_FILE` / `KEY_FILE` | 无 | 证书和私钥，都设了就直接用 HTTPS |
| `ADMIN_PASSWORD` | 自动生成 | 管理员密码（不设就保存在 `data/admin_password.txt`） |
| `DATA_DIR` | `./data` | 数据放哪 |
| `TRUST_PROXY` | 关 | 放在 nginx 等反向代理后面时设 `1` |
| `CLOUDFLARE` | 关 | 挂在 Cloudflare 后面时设 `1`，读取访问者真实 IP |
| `ROOM_IDLE_DAYS` | `30` | 多少天没人进出的房间自动清掉，`0` = 永不 |
| `MAX_CONN` | `200` | 同时最多多少个连接 |

浏览器只在 HTTPS（或 localhost）页面里开放加密功能，所以对外一定要用 HTTPS。
